Information Visualisation

Designing visual representations that make complex information easier to explore, interpret and communicate, with attention to audience, task, data structure and visual hierarchy.

Project focus

Python

Power BI

Exploratory analysis

Data storytelling

Dashboard thinking

The objective

Effective visualisation is not simply about making data attractive. The aim was to select and design visual representations that match the analytical question, the characteristics of the dataset and the information needs of the audience.

Approach

The workflow considered audience, analytical task, data type and visual encoding. Static graphics were appropriate when the objective was to communicate a clear narrative, while interactive views were considered when filtering, comparison and exploration added genuine analytical value.

  • Selected chart types according to the analytical question.
  • Applied hierarchy and labelling to improve readability.
  • Reduced unnecessary visual clutter.
  • Considered scale selection and accurate comparison.
  • Used visualisation as both an exploratory and explanatory tool.

Communication & decision support

The work developed my ability to move from raw data to a visual output that a non-technical audience can understand. This is particularly relevant to analytical roles where the value of an analysis depends on whether findings can be communicated clearly enough to support action.

Skills demonstrated

Data interpretation, visual communication, analytical judgement, audience awareness, dashboard design and evidence-led storytelling.
